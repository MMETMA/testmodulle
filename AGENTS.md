# Custom Project Guidelines

## Versioning Rule
Whenever you make any changes or modifications to the application code, configuration, or resources:
1. Increment `versionName` in `app/build.gradle.kts` following the patch sequence (e.g., `1.0.1` -> `1.0.2` -> `1.0.3` -> ...).
2. Increment `versionCode` by `+1` (e.g., `2` -> `3` -> `4` -> ...).
